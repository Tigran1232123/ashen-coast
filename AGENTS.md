# Берег обломков — правила обновления

**Текущее указание пользователя, 15 октября 2026: публикации на GitHub возобновлены.** Пользователь попросил: «как доделаешь выгрузи на гитхаб». После завершения и проверок V54 опубликовать исходники и отдельный релиз по порядку ниже. Не закрывать пользовательскую игру.

При добавлении новых персонажей проверять полный цикл ходьбы: ноги должны переступать, направление и фазы должны соответствовать перемещению; одной тряски тела недостаточно.

Исходный проект Unity: `AshenCoast`. Репозиторий игры: `https://github.com/Tigran1232123/ashen-coast`. Пользователь 15 октября 2026 года прямо разрешил обновлять этот репозиторий с каждым готовым обновлением игры. Повторное подтверждение публикации не требуется, если пользователь не изменил это указание.

После каждого готового игрового обновления:

1. Выполнить сборку и только проверки, затронутые изменениями. Не повторять старые проверки без причины. Не закрывать пользовательскую игру: сохранений пока нет.
2. Обновить номер версии, локальный запуск, документацию и архивы Windows/Unity. Для кооператива обе стороны должны использовать одинаковую сборку; идентификатор сборки в сетевом приветствии должен соответствовать выпускаемой версии.
3. Обновить исходники в репозитории игры. Не использовать старый `tigranisg-lab/5`: он содержит другой проект. Не добавлять туда файлы домашней папки, рабочие временные файлы, кэши Unity или данные доступа.
4. Публиковать отдельный релиз `vNN` с готовым Windows ZIP, исходным ZIP и контрольными суммами. Сохранять предыдущие релизы. Сначала загрузить и проверить файлы черновика, затем опубликовать его.
5. В ответе дать ссылку на новый релиз и отметить, что обоим игрокам нужна одна версия. Подключение: Esc → Кооператив; ведущий создаёт игру, гость вводит его IP и TCP-порт 27849. Для Radmin VPN используется IP из Radmin.

Настройка этого порядка сама по себе не требует нового релиза игры или повторения игровых тестов. Если GitHub недоступен, сохранить готовую локальную сборку и явно сообщить, что публикация ещё не завершена.
