# Берег обломков

Пиксельная 2,5D RPG для Windows, проект Unity 6000.6.5f1.

## Скачать и запустить

Откройте [последний релиз](https://github.com/Tigran1232123/ashen-coast/releases/latest), скачайте **AshenCoast-Windows-V49.zip** и распакуйте весь архив. Запустите `Запустить игру.cmd`. Unity для игры не требуется.

## Кооператив до четырёх игроков

У всех участников должна быть одна версия V49. Нажмите **Esc**, затем кнопку **«Кооператив»** в окне настроек.

- Ведущий нажимает **«Создать игру»** и передаёт свой IP остальным.
- Остальные вводят IP ведущего и порт **27849**, затем нажимают **«Подключиться»**.
- В одной домашней сети можно использовать Wi-Fi или кабель.
- Через интернет можно объединить компьютеры в одну сеть Radmin VPN; в игре вводите **IP ведущего из Radmin VPN**.

Дома и подземелья каждый игрок посещает независимо. Инвентари персонажей отдельные; хранилища, предметы на земле и состояние мира общие. Меню и карта одного игрока не останавливают остальных. Ведущий должен оставаться в игре.

[Подробное подключение и настройка брандмауэра](docs/COOP-V49.md).

Кооператив проверен четырьмя отдельными игровыми процессами на одном компьютере. Проверка через Radmin VPN на двух физических компьютерах пока не выполнена. Сохранений мира пока нет; восстановление персонажа после переподключения ещё не реализовано.
