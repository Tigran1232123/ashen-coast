# Берег обломков — локальная V53

Пиксельная 2,5D RPG для Windows, Unity 6000.6.5f1.

Публикации на GitHub временно приостановлены пользователем. Последняя опубликованная версия — V52; эта V53 находится в локальных архивах. Распакуйте весь AshenCoast-Windows-V53.zip и запустите «Запустить игру.cmd».

В V53 обновлены интерьеры улиток, движение каравана и людей, звук тренировок, смерть и добыча, размеры лягушек и производительность. Подробности: docs/CHANGELOG-V53.md, docs/CHECKS-V53.md, docs/ART-V53.md.

Кооператив: обоим нужна V53. Esc → Кооператив; ведущий создаёт игру, гость вводит его IP и TCP-порт27849. Для Radmin используется IP ведущего из Radmin. Локации независимые. Сохранений пока нет. Подробности: docs/COOP-V53.md.

Исходники: AshenCoast, сцена Assets/Scenes/Coast.unity. Состояние разработки: docs/CONTINUE.md. Старые релизы сохранены.
