# Берег обломков — V55

Пиксельная 2,5D RPG для Windows, Unity 6000.6.5f1.

[Скачать готовую игру V55](https://github.com/Tigran1232123/ashen-coast/releases/tag/v55). Распакуйте весь AshenCoast-Windows-V55.zip и запустите «Запустить игру.cmd». Unity устанавливать для игры не нужно.

В V55 исправлена синхронизация уже подобранной добычи и добавлен отдельный отчёт об ошибках кооператива. Все улучшения Крылатого стана, боя, персонажей и интерфейса V54 сохранены.

Кооператив: обоим нужна **V55**. **Esc → Кооператив**; ведущий создаёт игру, гость вводит IP ведущего и TCP-порт **27849**. Для Radmin используйте IP ведущего из Radmin. До четырёх игроков, независимые локации. [Подключение](docs/COOP-V55.md).
