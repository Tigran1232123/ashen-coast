# Берег обломков — V54

Пиксельная 2,5D RPG для Windows, Unity 6000.6.5f1.

[Скачать готовую игру V54](https://github.com/Tigran1232123/ashen-coast/releases/tag/v54). Распакуйте весь **AshenCoast-Windows-V54.zip**, запустите **Запустить игру.cmd**. Unity устанавливать для игры не нужно.

В V54 значительно переработан Крылатый стан: случайная планировка, десять отдельных уютных домов, резная Альвиэль и общий очаг, живые тренировки и разные пленники. Новые стрелы с физикой, сапоги и ролики, построение союзников, подробный червь и всплывающие свойства предметов. Также включены локальные улучшения V53.

Кооператив: обоим нужна **V54**. **Esc → Кооператив**; ведущий нажимает **Создать игру**, гость вводит его IP и TCP-порт **27849**, затем **Подключиться**. Для Radmin используйте IP ведущего из Radmin. До четырёх игроков, независимые локации. [Подключение](docs/COOP-V54.md).
