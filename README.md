# Берег обломков — V57

Пиксельная 2,5D RPG для Windows, Unity6000.6.5f1.

[Скачать V57](https://github.com/Tigran1232123/ashen-coast/releases/tag/v57). Распакуйте весь AshenCoast-Windows-V57.zip и запустите «Запустить игру.cmd». Unity для игры не требуется.

V57 исправляет смещение ног и деталей в кооперативе: постоянные имена частей, общая точка движения и передача тревоги таверны. Уменьшена частота полных снимков и объём сообщений игрока, сжатие перенесено в фоновый поток, старые сообщения движения заменяются свежими. Исправление seed V56 сохранено.

Обоим нужна **V57**. **Esc → Кооператив**; ведущий создаёт игру, гость вводит IP ведущего и TCP-порт **27849**. Для Radmin — IP ведущего из Radmin. [Подключение](docs/COOP-V57.md).
