# Берег обломков

Пиксельная 2,5D RPG для Windows, проект Unity 6000.6.5f1.

## Скачать и запустить

Скачайте **AshenCoast-Windows-V51.zip** из [последнего релиза](https://github.com/Tigran1232123/ashen-coast/releases/latest), распакуйте весь архив и запустите `Запустить игру.cmd`. Unity для игры не требуется.

V51 исправляет улиток-дома, добавляет сбор каравана, круглый лагерь с костром и отдыхом союзников, разные интерьеры, лягушку-персонажа и воскрешение. [Изменения V51](docs/CHANGELOG-V51.md).

## Кооператив до четырёх игроков

Всем нужна одна версия **V51**. Выберите персонажа; ведущий выбирает число игроков, затем **Esc → Кооператив → Создать игру**. Гость вводит IP ведущего и TCP-порт **27849**, затем нажимает **Подключиться**. Через Radmin VPN используется IP ведущего из Radmin. [Подробная инструкция](docs/COOP-V51.md).

Локации каждый посещает независимо. Личные персонажи, инвентари и войска, общие вещи и хранилища. Четыре улитки распределяются на 1–4 игроков; при игре втроём четвёртая общая. Команда движения относится ко всему каравану.

Проверены четыре отдельных игровых процесса на одном компьютере. Соединение через Radmin на двух физических ПК ещё не проверено. Ведущий должен оставаться в игре. Постоянных сохранений и восстановления отключённого персонажа пока нет.
