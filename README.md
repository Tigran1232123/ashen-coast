# Берег обломков · V58

2.5D-игра на Unity. Исходный проект — папка AshenCoast. Готовая Windows-версия и полный Unity-проект доступны в [релизе V58](https://github.com/Tigran1232123/ashen-coast/releases/tag/v58).

WASD — движение; E — инвентарь; Esc — закрыть инвентарь / настройки; Q — медитация; M — карта; T — скорость ×5 и бесконечные здоровье/мана. Лук: удерживать ЛКМ две секунды и отпустить. Арбалет: поставить на землю, ПКМ — управление, ЛКМ — стрельба.

Изменения: docs/CHANGELOG-V58.md. Кооператив: docs/COOP-V58.md. Проверки: docs/CHECKS-V58.md. Рисунки и промпты: docs/ART-V58.md.

Для кооператива обеим сторонам нужна V58. TCP 27849; в Radmin используйте IP ведущего из Radmin. Сохранений пока нет.
