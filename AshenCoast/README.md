# Берег обломков

Пиксельная 2,5D RPG для Windows, проект Unity 6000.6.5f1.

## Скачать и запустить

Скачайте **AshenCoast-Windows-V50.zip** из [последнего релиза](https://github.com/Tigran1232123/ashen-coast/releases/latest), распакуйте весь архив и запустите `Запустить игру.cmd`. Unity для игры не требуется.

V50 добавляет четыре передвижных улитки-дома, личные комнаты и казармы, размещение войск, выбор числа игроков и командование своим отрядом. [Все изменения V50](docs/CHANGELOG-V50.md).

## Кооператив до четырёх игроков

Всем нужна одна версия V50. Ведущий выбирает число игроков при старте, затем **Esc → Кооператив → Создать игру**. Гость вводит IP ведущего и TCP-порт **27849**, затем нажимает **Подключиться**. Через Radmin VPN используется IP ведущего из Radmin. [Подробная инструкция](docs/COOP-V50.md).

Дома и подземелья каждый посещает независимо. Личные инвентари и войска, общие вещи и хранилища. Улитки распределяются на 1–4 игроков; в игре втроём четвёртая общая. Меню одного игрока не останавливает остальных. Ведущий должен оставаться в игре.

Проверено четырьмя отдельными процессами на одном компьютере. Соединение Radmin на двух физических компьютерах ещё не проверено. Сохранений мира и восстановления отключённого персонажа пока нет.
