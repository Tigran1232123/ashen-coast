# Берег обломков

Пиксельная 2,5D RPG для Windows. Проект Unity 6000.6.5f1.

## Скачать и запустить

Скачайте **AshenCoast-Windows-V52.zip** из [последнего релиза](https://github.com/Tigran1232123/ashen-coast/releases/latest), распакуйте весь архив и запустите `Запустить игру.cmd`. Unity для игры не требуется.

V52 исправляет обрезанные спрайты лягушки в меню и при движении. [Изменения V52](docs/CHANGELOG-V52.md).

В игре: четыре улитки-дома с казармами, круглый лагерь, союзные отряды, поселение амазонок, книги заклинаний, выбор человека или лягушки, воскрешение.

## Кооператив до четырёх игроков

Всем нужна одна **V52**. Ведущий выбирает число игроков и открывает **Esc → Кооператив → Создать игру**. Гость вводит IP ведущего и TCP-порт **27849**, затем нажимает **Подключиться**. Для Radmin VPN используется IP ведущего из Radmin. [Подключение](docs/COOP-V52.md).

Локации каждый посещает независимо. Персонажи, инвентари и войска личные; хранилища общие. Команда передвижения относится ко всем четырём улиткам.

Кооператив проверялся четырьмя игровыми процессами на одном компьютере. Соединение через Radmin на двух физических ПК ещё не проверено. Ведущий остаётся в игре. Постоянных сохранений и восстановления отключённого персонажа пока нет.
