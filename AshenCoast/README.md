# Берег обломков — V56

Пиксельная 2,5D RPG для Windows, Unity 6000.6.5f1.

[Скачать игру V56](https://github.com/Tigran1232123/ashen-coast/releases/tag/v56). Распакуйте весь AshenCoast-Windows-V56.zip и запустите «Запустить игру.cmd». Unity для игры не требуется.

V56 исправляет отказ гостя при Different world seed: гость принимает случайный мир ведущего вместе с его берегом, фортом, пещерой и деревней. Личные предметы гостя сохраняются. Все улучшения V54 и исправление синхронизации добычи V55 сохранены.

Кооператив: обоим нужна **V56**. **Esc → Кооператив**; ведущий создаёт игру, гость вводит IP ведущего и TCP-порт **27849**. Для Radmin используйте IP ведущего из Radmin. [Подключение](docs/COOP-V56.md).
