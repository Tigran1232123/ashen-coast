# Берег обломков · V59

2.5D-игра на Unity. Исходный проект — AshenCoast. [Готовая Windows-версия и исходный архив V59](https://github.com/Tigran1232123/ashen-coast/releases/tag/v59).

V59 исправляет рывки от повторного поиска маршрутов персонажей. Изменения: docs/CHANGELOG-V59.md. Проверки и ограничения замера: docs/CHECKS-V59.md. Кооператив: docs/COOP-V59.md. Новое оружие, река и другие механики описаны в docs/CHANGELOG-V58.md. Рисунки и промпты: docs/ART-V58.md.

WASD — движение; E — инвентарь; Esc — закрыть инвентарь / настройки; Q — медитация; M — карта; T — скорость ×5 и бесконечные здоровье/мана. Лук: удерживать ЛКМ две секунды и отпустить. Арбалет: поставить на землю, ПКМ — управление, ЛКМ — стрельба.

Для кооператива обеим сторонам нужна V59. Esc → Кооператив, TCP 27849; в Radmin используйте IP ведущего из Radmin. Сохранений пока нет.
