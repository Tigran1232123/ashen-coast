# Кооператив V55

1. Оба игрока скачивают AshenCoast-Windows-V55.zip и распаковывают весь архив в отдельную папку. Запуск — «Запустить игру.cmd».
2. Ведущий: Esc → Кооператив → нужное число игроков → Создать игру. TCP-порт 27849.
3. Гость: Esc → Кооператив → IP ведущего и порт 27849 → Подключиться.
4. Через Radmin VPN оба входят в одну сеть Radmin, гость вводит IP ведущего из Radmin.

Обоим нужна именно V55; V54 несовместима с V55. Сохранений пока нет: закрытие ведущего завершит текущий мир.

Если ошибка повторится, у гостя в окне кооператива нажмите «Открыть отчёт об ошибке» и передайте файл разработчику. Файл Coop-Sync-Error.txt сохраняется рядом с AshenCoast.exe, а если там нет прав записи — в папке данных игры.
