# Кооператив V54

1. Каждый скачивает **AshenCoast-Windows-V54.zip**, распаковывает весь архив в свою папку и запускает «Запустить игру.cmd».
2. Ведущий выбирает нужное число игроков, начинает игру, нажимает **Esc → Кооператив → Создать игру**. TCP-порт — **27849**.
3. Гость открывает **Esc → Кооператив**, вводит IP ведущего, порт **27849** и нажимает **Подключиться**.
4. Через Radmin VPN оба входят в одну сеть Radmin, а гость использует **IP ведущего из Radmin**. В обычной локальной сети используется его локальный IPv4.

Обоим нужна одна и та же сборка V54; V49–V53 несовместимы с ней. Игра поддерживает до четырёх игроков и независимые переходы между локациями. Планировка деревни приходит от ведущего.

Если Windows спрашивает доступ к сети, разрешите игре доступ к используемой доверенной сети. Сохранений пока нет: закрытие ведущего завершает текущий мир.

В этой версии проверены два процесса на одном компьютере: подключение, случайная деревня, независимый вход гостя в дом и попадание его стрелы по существу ведущего. Два физических компьютера и Radmin в этой сессии не проверялись.
