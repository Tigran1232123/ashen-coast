# Кооператив V59

Оба игрока полностью распаковывают AshenCoast-Windows-V59.zip в отдельную папку и запускают «Запустить игру.cmd».

1. Ведущий: Esc → Кооператив → создать игру. TCP-порт 27849.
2. Гость: Esc → Кооператив → IP ведущего, порт 27849 → подключиться.
3. Через Radmin VPN используйте IP ведущего из Radmin; оба должны быть в одной сети.

Сборки V58 и V59 несовместимы. Номер версии виден на начальном экране. Медитация ускоряет время только при участии всех подключённых игроков. В разных помещениях это правило также действует.
При ошибке используйте кнопку «Открыть отчёт об ошибке» в меню кооператива.
