# Проверки V55

Только проверки изменённой синхронизации, без повторного прогона деревни, рисунков, боя и других функций V54.

Сборка Windows x64 — Unity 6000.6.5f1, BuildCurrent, bundleVersion/hello/packet 55.

Два настоящих процесса через TCP loopback: позднее подключение к миру после слияния монет, начальные инвентари и снимки, действительная добыча, отсутствие уже подобранного нулевого стака, совместимость с отметкой о подборе без восстановления содержимого, 12 секунд последующих обновлений, отключение и повторное подключение. Отдельно воспроизведено исключение старого пути Restore() для обнулённого предмета; проверка действительных предметов не ослаблена. Проверено скрытие существующей добычи по отметке и создание отдельного отчёта с типом пакета и исключением.

host: RESULT 13 passed; 0 failed
guest: RESULT 11 passed; 0 failed

Исходный сбой друга без его журнала нельзя уверенно отождествить с этим сценарием. Два физических компьютера и Radmin в этой сессии не проверялись. Пользовательские процессы не закрывались.
