# Как играть вместе в V49

## Что скачать

Оба игрока скачивают **AshenCoast-Windows-V49.zip** из раздела Releases и распаковывают весь архив. Запускают `Запустить игру.cmd`. Unity устанавливать не нужно. Нельзя передавать только EXE: ему нужны все соседние папки и файлы.

## Одна домашняя сеть

1. Подключите компьютеры к одному домашнему роутеру через Wi-Fi или кабель.
2. Ведущий открывает **Esc → кнопка «Кооператив» в окне настроек** и нажимает **Создать игру**.
3. Ведущий передаёт остальным свой IPv4-адрес из строки «Адрес ведущего».
4. Остальные открывают то же меню, вводят адрес ведущего, оставляют порт **27849** и нажимают **Подключиться**.

В игре может быть до четырёх игроков, включая ведущего. Дома, таверну, форт и подземелье можно посещать независимо. Мир продолжает жить, когда один игрок открывает карту или меню.

## Через Radmin VPN

1. Все участники устанавливают Radmin VPN.
2. Один создаёт сеть с именем и паролем, остальные подключаются к ней.
3. В игре ведущий нажимает **Создать игру**.
4. Остальные в поле «Адрес» вводят **IP ведущего из окна Radmin VPN**, порт **27849**, затем нажимают **Подключиться**.

Это подключение по виртуальной локальной сети. В этой версии соединение через Radmin VPN ещё не проверялось на двух физических компьютерах. Проверка четырёх отдельных игровых процессов выполнена на одном компьютере.

Инструкция Radmin: https://www.radmin-vpn.com/help/

## Если соединение не устанавливается

- У всех должна быть одна версия V49.
- Ведущий должен держать игру открытой. Его выход завершает сетевую сессию.
- Разрешите **AshenCoast.exe** в брандмауэре Windows для используемой сети. Для домашней сети обычно нужен профиль «Частная». Профиль VPN может отличаться; правило должно действовать для его текущего профиля.
- Для настройки: **Win+R → firewall.cpl → Разрешение взаимодействия с приложением… → Изменить параметры**. Если игра отсутствует, добавьте EXE из распакованной сборки.
- Сетевой порт игры — **TCP 27849**. Если порт занят другой программой, ведущий выбирает иной порт, а все участники вводят тот же номер.
- Гостевой Wi-Fi иногда изолирует компьютеры друг от друга; используйте обычную домашнюю сеть.

Инструкция Windows: https://support.microsoft.com/en-us/windows/security/windows-security/firewall-and-network-protection-in-the-windows-security-app

Сохранений мира пока нет: после закрытия игры начинается новый мир. Переподключение возвращает игрока в сессию с новым локальным персонажем; восстановления прежнего инвентаря после отключения пока нет.
