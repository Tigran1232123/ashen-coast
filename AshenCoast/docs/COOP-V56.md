# Кооператив V56

1. Оба игрока скачивают AshenCoast-Windows-V56.zip и полностью распаковывают его в отдельную папку. Запуск — «Запустить игру.cmd».
2. Ведущий: Esc → Кооператив → число игроков → Создать игру. TCP-порт 27849.
3. Гость: Esc → Кооператив → IP ведущего, порт 27849 → Подключиться.
4. Для Radmin VPN оба входят в одну сеть, гость указывает IP ведущего из Radmin.

Обоим нужна V56; версии V55 и V56 несовместимы. Гость автоматически принимает случайный мир ведущего, подбирать одинаковый seed вручную не требуется.

Сохранений пока нет. Закрытие ведущего завершает его мир. Уже открытая старая сборка автоматически не обновляется.
При другой ошибке используйте «Открыть отчёт об ошибке» в окне кооператива: Coop-Sync-Error.txt содержит версию, этап и исключение.
