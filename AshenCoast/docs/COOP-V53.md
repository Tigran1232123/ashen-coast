# Кооператив — локальная V53

Оба компьютера должны использовать одинаковую **V53**. Передайте второму игроку весь архив `AshenCoast-Windows-V53.zip`: загрузки обновлений на GitHub сейчас приостановлены, там остаётся V52.

1. Распакуйте весь архив на каждом компьютере и запустите `Запустить игру.cmd`.
2. Ведущий выбирает плановое количество игроков при начале мира.
3. Ведущий: **Esc → Кооператив → Создать игру**.
4. Гость: **Esc → Кооператив**, IP ведущего, TCP-порт **27849**, затем **Подключиться**.

При общей локальной сети используется локальный IP ведущего. При Radmin VPN оба входят в одну сеть Radmin, гость вводит IP ведущего из Radmin. Приложению нужен доступ через брандмауэр в используемой сети.

Игроки посещают локации независимо. Команда передвижения относится ко всем четырём улиткам, перед отправлением длится минутный сбор. У каждого свои персонаж, инвентарь и войска.

Изменения V53 проверялись в двух игровых процессах на одном компьютере. Два физических ПК и Radmin в этом обновлении не проверялись. Сохранений пока нет; ведущий должен оставаться в игре.
