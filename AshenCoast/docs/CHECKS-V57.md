# Проверки V57

Windows x64, Unity 6000.6.5f1, BuildCurrent. App57.0, packet/hello57.
Два процесса TCP loopback с обычной инициализацией и разными seed. Поздний вход в уже встревоженную таверну, динамическое оружие, 8 направлений × 8 полученных фаз ходьбы, общий якорь частей персонажа, искусственное замедление потока отправки на 70мс/сообщение, сохранность личного мешка и смена владельца симуляции локации.
Очередь проверена на1000 состояниях: один слот движения, команды не теряются и сохраняют порядок. Проверен отдельный поток сжатия. Старый способ интерполяции воспроизводит отклонение ног.
