# Кооператив V57

1. Оба скачивают AshenCoast-Windows-V57.zip и полностью распаковывают архив в отдельную папку. Запуск — «Запустить игру.cmd».
2. Ведущий: Esc → Кооператив → число игроков → Создать игру. TCP-порт 27849.
3. Гость: Esc → Кооператив → IP ведущего, порт 27849 → Подключиться.
4. Для Radmin VPN оба входят в одну сеть, гость использует IP ведущего из Radmin.

Обоим нужна V57; V56 несовместима. Исправление случайного seed V56 сохранено. Сохранений пока нет. Открытая старая сборка автоматически не обновляется.
При ошибке используйте «Открыть отчёт об ошибке» в кооперативе: Coop-Sync-Error.txt содержит версию, этап и исключение.
