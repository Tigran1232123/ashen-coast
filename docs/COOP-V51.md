# Как играть вместе — V51

1. Все скачивают **AshenCoast-Windows-V51.zip** и распаковывают весь архив. Запустите `Запустить игру.cmd`.
2. В начале выберите персонажа. Ведущий также выбирает количество игроков в мире.
3. Ведущий нажимает **Esc → Кооператив → Создать игру**. TCP-порт — **27849**.
4. Гости нажимают **Esc → Кооператив**, вводят IP ведущего и порт **27849**, затем **Подключиться**.

В одной домашней сети используется локальный IP ведущего. Через Radmin VPN все входят в одну сеть Radmin и в игре вводят IP ведущего из Radmin. Брандмауэр ведущего должен разрешать этой сборке игры входящие подключения в используемой сети.

У каждого свой персонаж, инвентарь и войска. Локации можно посещать независимо. Команда передвижения относится ко всем четырём улиткам. При отправлении союзники собираются минуту; опоздавшие оказываются внутри. Прибыв, караван разбивает круглый лагерь. Спрятавшаяся улитка задерживает весь караван.

ПКМ по двери улитки — вход; ПКМ по её телу — карта. Удержание ЛКМ двигает карту, ПКМ выбирает открытую точку назначения. Z останавливает караван на 15 секунд. ПКМ по союзнику позволяет отправить его домой. ЛКМ по портрету мага вызывает взрыв.

Игрока можно воскресить в течение минуты после смерти: другой участник с открытой огненной книгой и свитком «Возвращение» рисует вокруг его тела замкнутый полукруг. Персонаж и вещи сохраняются, здоровье восстанавливается до 50%.

Всем нужна одна версия **V51**. Проверены четыре процесса на одном компьютере; соединение через Radmin на двух физических ПК ещё не проверено. Ведущий должен оставаться в игре. Постоянных сохранений и восстановления отключённого персонажа пока нет.
