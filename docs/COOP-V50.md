# Как играть вместе — V50

1. Все скачивают **AshenCoast-Windows-V50.zip** и распаковывают архив целиком. Откройте `Запустить игру.cmd`.
2. Ведущий выбирает в начале, сколько игроков будет в мире, затем нажимает **Начать**. Число игроков можно изменить перед созданием сессии в окне кооператива.
3. Ведущий нажимает **Esc → Кооператив → Создать игру**. Порт — **27849**.
4. Остальные нажимают **Esc → Кооператив**, вводят IP ведущего и порт **27849**, затем **Подключиться**.

В одной домашней сети используется локальный IP ведущего. Через Radmin VPN все входят в одну сеть Radmin и в игре вводят IP ведущего, показанный в Radmin. Брандмауэр ведущего должен разрешать этой сборке игры входящие подключения в используемой сети.

У каждого отдельный персонаж, инвентарь и войска. В комнаты, таверну и подземелья можно входить независимо. Улитки распределяются по выбранному числу игроков. Четвёртая улитка в игре втроём общая, но каждый управляет только своими бойцами. Команда передвижения относится ко всем четырём улиткам.

**Управление улитками:** ПКМ по двери — вход; ПКМ по телу — карта движения; удержание ЛКМ — перемещение карты; ПКМ по карте — общая цель. Z — свист и остановка каравана на 15 секунд. ПКМ по союзнику — отправить домой; портрет улитки вверху — отправить войска; ЛКМ по портрету мага — взрыв.

Обеим сторонам нужна одинаковая версия V50. Проверено четыре процесса на одном компьютере; соединение через Radmin на двух физических ПК ещё не проверено. Ведущий должен оставаться в игре. Сохранений и восстановления отключённого персонажа пока нет.
