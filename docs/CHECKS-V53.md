# Проверки локальной V53

Проверялись только затронутые системы. Старые полные игровые проверки не запускались заново, пользовательские игры не закрывались.

- `work/Verification-V53-map/results.txt`: 28 passed / 0 failed. Размер лягушки, движение и расстановка четырёх улиток, команда назначения точки, мебель, походка людей, ограничение звука, размер тел, падение, полёт добычи и принадлежность после воскрешения.
- `work/Verification-V53-final/results.txt`: 17 passed / 0 failed. Уточнённые двери/посуда, руки лягушки, скрытый сетевой облик, сохранение анимации после оптимизации меша, мирное воскрешение и начало смерти всех восьми обычных семейств.
- `work/Verification-V53-LAN`: два настоящих процесса. Пройдены независимые локации, выпадение добычи у симулятора чужой области, нейтральное воскрешение и команда каравана, когда ведущий внутри улитки. Ранняя проверка облика скрытой лягушки выявила отдельную ошибку; она исправлена и проверена следующим сценарием.
- `work/Verification-V53-proxy`: отдельные два процесса, host 6 / 0 и guest 4 / 0. Правильный уменьшенный спрайт лягушки и её анимация смерти у ведущего, пока гость находится в другой локации.
- Финальное уточнение вырезки руки проверяется отдельно в `work/Verification-V53-arm`; остальные проверки после него не повторяются.

Изображения получены через Camera.Render и просмотрены. Для команды карты проверялся обработчик выбора точки с реальной исследованностью и движением всех домов. Искусственный Event вне OnGUI в скрытом окне Unity имеет тип Ignore; такой вызов не считается физическим кликом мышью по окну.

Замер CPU на одной машине: 100 проходов старого отслеживания существ — 34,37 мс, нового — 0,39 мс. Счётчик выделенной памяти Mono возвращает нули, поэтому количественный вывод о памяти по нему не делается. В коде устранены повторные массивы вершин, постоянные выборки тел для каждого живого существа, сортировка всего открытого списка пути и создание одинаковых искровых спрайтов. Общий прирост FPS не измерялся.

Финальная сборка: `work/unity-build-v53-local-final.log`, метод BuildCurrent, без повторения старого ModelChecks. Сетевой пакет и приветствие: 53, bundleVersion: 53.0.
