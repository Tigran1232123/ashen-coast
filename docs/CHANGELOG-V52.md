# V52 — исправление спрайтов лягушки

Исправлена нарезка всех 32 поз персонажа-лягушки. Кадры определяются по фактическим промежуткам между силуэтами на листе. Лягушка больше не обрезается в меню выбора и во время движения; рядом не появляется фрагмент соседнего кадра.

Исправлен развёрнутый в другую сторону кадр при ходьбе влево. Проверены четыре фазы каждого из восьми направлений, движение самого персонажа и отображение лягушки второго игрока. Другие игровые системы повторно не проверялись.

Сборка и сетевое приветствие обновлены до V52. Для кооператива всем нужна одна V52.
